1 ASR 层 — 语音转文字（A路）

🔊 阿里云百炼 DashScope

  • API: qwen3-asr-flash 模型
  • 输入: WebM/WAV 音频二进制
  • 输出: 原始ASR中文文本
  • 环境变量: DASHSCOPE_API_KEY
  • 3次重试 / 45s超时

🔧 ASR 后处理 asr_correction.py

  • 混淆词纠错（医学专科词典）
  • 反义词消歧
  • 语音识别语言模型 hotwords 注入
  • 输出 A = corrected_text
A路: ASR文本 → 性别/妊娠冲突检测 → PII脱敏(姓名/手机号)
2 路由决策 — 智能分流（Agent决策节点）

🧠 三路分流 main.py:structure()

  • 胎儿快速通道: 关键词匹配(产科/孕/BPD...) → 直接调用 fill_fetal_template
  • 正常报告快速通道: 无异常关键词 → 规则引擎直出，跳过全部LLM调用
  • 通用路径: 触发完整 ABCDEF v3 流水线

⚡ 并行执行 asyncio.gather

  • B路 LLM 与 C路 Regex 并行调用
  • D路依赖B路结果（B→规则引擎再分析）
  • EF合并依赖ABCD全部结果
3 LLM 层 — 自由生成（B路）

🤖 DeepSeek Chat API

  • 模型: deepseek-chat
  • API: https://api.deepseek.com/v1
  • 温度: 0.1（低创造性）
  • max_tokens: 4096
  • 2次重试
  • 函数: generate_free_report()

📝 System Prompt 构建

  • 角色: 资深超声科主任医师
  • 检查类型 + 覆盖脏器列表
  • 输出JSON Schema约束
  • 缺失值填 ___mm 占位
  • 口语→标准术语

🔧 JSON 解析修复

  • 提取 Markdown fences
  • 补全未闭合括号
  • 截断末行重试
  • ICD-10编码补全
  • 输出: {study_see, study_hint[], recommendation}
4 规则引擎层 — 正则提取（C路）

📏 rule_engine.py

  • 加载 knowledge/ JSON配置
  • 矛盾检测规则、正常范围规则
  • 性别保护规则、孕周约束
  • 药物-超声互斥规则

📋 template_engine_v2.py

  • template_filler: CSV模板字段→文本变量替换
  • template_loader: 528份超声模板
  • 关键词+TF-IDF 模板匹配
  • 数值正则提取 (mm/cm/g等)

📐 fixed_template_engine.py

  • process_with_fixed_template()
  • 意图检测: intent_detector.py
  • 6大类标签匹配 (腹部/妇产/心脏/甲状腺/血管/泌尿)
5 增强层 — B→规则引擎再分析（D路）

🔄 D路: LLM结果二次提取

  • 输入: B路LLM生成的 study_see (HTML stripped)
  • 处理: match_and_fill_optimized() 再次匹配模板
  • 目的: 从LLM自由生成中提取结构化数值
  • 兜底: process_with_fixed_template → fixed模板填充
6 模板融合层 — 选举+填充+验证（EF合并）

🧬 EF合并 — DeepSeek v4-flash 一次完成

  • select_fill_and_validate() 函数
  • 输入: ASR原文 + B/C/D三路结果 + 候选模板列表(前8)
  • LLM任务: ①选最优模板 ②填测量值 ③标注voice/unfill ④交叉验证
  • Template score < 50 → 回退到B/C混合自由生成
  • 输出: 最终结构化报告HTML (带颜色标记)
7 验证层 — 多维度质量控制

L2 固定文本完整性

模板关键词 vs 填充文本比对，缺失>30%触发降级

L4 内容溯源

规则引擎数值 vs 最终报告数值，检测遗漏/引入

L5 医疗合规

矛盾描述检测(如"可见"+"未见")、性别脏器冲突

  • 橙色下划线: 未填充的占位符
