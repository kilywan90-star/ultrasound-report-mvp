## 一、字段说明（每列的「中文含义」）

| 字段名 | 中文含义 | 说明 |
|--------|----------|------|
| `rid` | 疾病ID | 唯一编号，一个rid对应一种模板 |
| `discname` | 疾病名称 | 如"脂肪肝"、"甲状腺单发结节" |
| `viscname` | 检查项目 | 全部=超声 |
| `modulename` | 系统模块 | 全部=UIS |
| `discgroup` | 疾病分组 | 肝脏、甲状腺疾病、前列腺等 |
| `tpl_INFO1` | 通用模板 | 前半段=所见描述，后半段=诊断提示 |
| `rpt_StudySee` | 原始报告所见 | 医生写的实际所见原文 |
| `rpt_StudySee_Full` | 原始报告完整版 | 扩增版本 |

## 二、变量说明

模板中用「花括号 {}」标注**需要替换的变量**，下面是所有变量类型：

### ▶ 尺寸变量（6类）

| 变量名 | 格式举例 | 含义 | 真实示例值 |
|--------|----------|------|-----------|
| `{结节大小}` | 数字×数字 mm | 结节/囊肿/肿块的长径×短径 | 18×14mm |
| `{管腔内径}` | 数字 mm | 血管/胆管/输尿管的管径 | 30mm |
| `{壁厚度}` | 数字 mm | 管壁/囊壁/甲状腺峡部厚度 | 4mm |
| `{扩张宽度}` | 数字 mm | 肾窦分离/胆管扩张的宽度 | 2.2mm |
| `{IMT厚度}` | 数字 mm | 颈动脉内中膜厚度 | 1.2mm |
| `{粗测尺寸}` | 数字×数字×数字 mm | 前列腺等器官的粗略三径 | 48×34×29mm |

### ▶ 回声性质（7类）

| 类别 | 包含说法 | 对应什么情况 |
|------|----------|--------------|
| 无回声 | "无回声" | 液体/囊肿 |
| 低回声 | "低回声""稍低回声""弱回声" | 实性占位 |
| 等回声 | "等回声" | 和周围组织差不多 |
| 高回声 | "高回声""稍高回声" | 比正常组织亮 |
| 强回声 | "强回声" | 钙化/结石 |
| 混合回声 | "混合回声""囊实性""不均质" | 多种成分混杂 |
| 中等回声 | "中等回声" | 介于低和高之间 |

### ▶ 血流信号（6种模式）

| 模式 | 原文描述 | 提示什么 |
|------|----------|----------|
| 无血流 | "未见明显血流信号" | 倾向良性 |
| 点状血流 | "点状血流信号""少许血流" | 交界性 |
| 条状血流 | "条状血流信号""线状血流" | 实性占位 |
| 丰富血流 | "血流丰富""明显增多" | 需警惕恶性 |
| 环状血流 | "周边见点状/环状血流" | 可能TI-RADS 3类 |
| 特殊征象 | "火海征""海岛征" | 甲亢或桥本 |
