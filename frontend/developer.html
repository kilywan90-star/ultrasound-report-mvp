API 参考

POST /v1/transcribe — 语音→报告

上传音频文件, 返回结构化超声报告。支持 wav/mp3/webm 格式, 最大 50MB。

curl -X POST https://47.109.151.238:8800/v1/transcribe \ -H "Authorization: Bearer sk-YOUR_API_KEY" \ -F "audio_file=@recording.wav" \ -F 'patient_context={"gender":"男","age":52,"exam_type":"腹部超声"}'

POST /v1/structure — 文本→报告

直接提交 ASR 文本, 返回结构化报告。

curl -X POST https://47.109.151.238:8800/v1/structure \ -H "Authorization: Bearer sk-YOUR_API_KEY" \ -H "Content-Type: application/json" \ -d '{"text":"肝脏大小正常,胆囊壁光滑,未见异常","patient_context":{"exam_type":"腹部超声"}}'

GET /v1/usage

查询当前租户的月度用量统计。

curl -H "Authorization: Bearer sk-YOUR_API_KEY" \ https://47.109.151.238:8800/v1/usage

GET /v1/health

健康检查, 不需要鉴权。

curl https://47.109.151.238:8800/v1/health
